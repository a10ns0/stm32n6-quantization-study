# Publicación

Repositorio público solicitado por el autor: https://github.com/a10ns0/stm32n6-quantization-study.

La publicación no asigna una licencia al código propio ni cambia las licencias de terceros. La carpeta material_privado_no_publicar permanece excluida. También se excluyen los CSV de entradas radiográficas del proyecto ST, por contener datos derivados del dataset cuyo permiso de redistribución queda pendiente. Los reportes y resultados agregados permanecen disponibles. No hay CI de hardware ni entrenamientos ejecutados en GitHub.

## Carga manual

Descomprima el ZIP. Suba el contenido de stm32n6-quantization-study, de modo que README.md quede en la raíz del repositorio. GitHub no descomprime automáticamente un ZIP subido como archivo. Para cargar el árbol completo se recomienda GitHub Desktop: clone el repositorio existente, copie los archivos extraídos dentro de la copia local, cree un commit y seleccione Push origin. Incluya .gitignore y los archivos de configuración de STM32.

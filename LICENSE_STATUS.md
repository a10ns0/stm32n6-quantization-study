# Estado de licencias

No se ha elegido licencia para el código propio; por eso no se añade un archivo LICENSE que conceda permisos no autorizados. MIT permite reutilización amplia conservando aviso; BSD-3-Clause añade restricción de respaldo por nombres; Apache-2.0 incorpora condiciones de patentes. La elección corresponde al autor y debe considerar obligaciones institucionales y componentes derivados. Estas opciones no relicencian material ajeno.

Los proyectos ST conservan sus LICENSE: SLA0104 para el paquete donde corresponde, licencias HAL/Device y Apache para CMSIS según sus avisos locales. Se conservan los avisos de copyright. Las bibliotecas precompiladas son necesarias para ciertos builds y tienen condiciones propias. No se declaran software propio ni se relícen­cian globalmente.

Los PDF científicos no están incluidos. Los datasets y checkpoints recuperados se entregan fuera del repositorio en material_privado_no_publicar hasta verificar sus licencias y correspondencia con los experimentos. Las salidas de notebooks pueden incorporar figuras o fragmentos de terceros: requieren revisar atribución antes de publicación pública. Los logs incluyen rutas de usuario; se conservan para trazabilidad y deben revisarse antes de publicación pública.

Se recomienda iniciar con un repositorio privado. Pasarlo a público requiere resolver licencia propia, permisos de datos/modelos y revisión de rutas/datos personales. No se afirma que todo el árbol esté autorizado para redistribución pública por el solo hecho de estar disponible localmente.
